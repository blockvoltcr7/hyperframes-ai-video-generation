# Product

**Archon**

An open-source workflow engine for deterministic and repeatable AI coding processes, defined via YAML-based workflow files.

# Positioning

Archon is for development teams who want structured, reliable AI-assisted coding — encoding repeatable phases like planning, implementation, validation, and PR creation so AI fills in intelligence within predetermined structures, not chaos.

# Value Proposition

Archon eliminates inconsistent AI agent behavior by giving teams a workflow layer: same workflow, same sequence, every time. It combines deterministic nodes (bash scripts, tests) with AI nodes (planning, code generation) to produce reliable, auditable results. Think Dockerfiles for AI coding — composable, version-controlled, and shareable across teams.

# Features

1. **Repeatable execution** — workflows run in the same sequence on every invocation
2. **Isolated git worktrees** — each run gets its own environment for safe parallel processing
3. **Composable nodes** — mix deterministic bash/test steps with AI-powered planning and generation
4. **Multi-platform triggers** — CLI, Web UI, Slack, Telegram, Discord, and GitHub webhooks
5. **17 built-in workflows** — issue fixing, PR review, feature development, refactoring, and more
6. **Fully customizable** — define and commit your own workflows directly to your repository
7. **MIT licensed** — open source, no lock-in

# CTA

**Quick install (30 sec):** `curl -fsSL https://archon.diy/install | bash`

**Full setup (5 min):** Clone the repo, run `bun install` and `claude`, then say "Set up Archon"
