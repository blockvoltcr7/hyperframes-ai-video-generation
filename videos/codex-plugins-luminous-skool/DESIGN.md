# Codex Plugins — Luminous Signature design

## Teaching objective

Give a new Codex user a durable mental model and a first practice loop in about 90 seconds. The film should feel like a premium technical keynote rather than a screen-recording tutorial.

## Visual grammar

- Canvas: near-black navy `#030712`; no pure black except temporary cut seams.
- Structure: electric blue `#3B82F6` for routes, dividers, progress, and selected states.
- Transformation: violet `#8B5CF6` / periwinkle `#818CF8` for capability changes and explicit invocation.
- Endpoint: pink `#EC4899` only for final decisions, terminal actions, and one-shot pulses.
- Type: Space Grotesk for display and labels; Inter for supporting copy. All instructional text remains HTML.
- Surfaces: translucent dark cards, thin cool-white borders, soft radii, no heavy shadows.

## Motion grammar

- Signature ease: `power3.out` for long-tail arrivals; short `power2.inOut` for connector traces.
- One dominant motion engine per frame: kinetic swap, constellation assembly, station pan, split comparison, trust rings, or submit-and-resolve.
- Important labels hold after arrival. No looping glow, breathing, or screensaver drift.
- Generated video is used only where organic, cinematic transformation adds meaning; exact UI and teaching copy stay deterministic.

## Generated-media plan

- `plugin-bundle-hero`: luminous capability core assembling in an abstract technical chamber; animate for 15 seconds with PixVerse C1.
- `install-invoke-path`: luminous pathway connecting four abstract workstations; animate for 15 seconds with PixVerse C1.
- `permission-boundary`: nested transparent trust shells around a capability core; use as a static depth plate.

The generated imagery contains no words, logos, watermarks, or imitation product UI. HTML overlays provide the lesson's exact terminology.
